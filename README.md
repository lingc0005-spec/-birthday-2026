# 生日祝福页（易辰 · 2026）

一个单文件可发布的生日祝福网页：点开锁屏播放音乐，14 位游戏角色在仿微信留言板里送上祝福。

## 文件说明
- `index.html` —— 寿星版（易辰，成品）
- `生日祝福-模板版.html` —— 模板版：可自行改歌词、头像、背景音乐

## 怎么自定义（用模板版）
1. **换背景音乐**：把新音频放进 `assets/`，替换 `肖邦a小调圆舞曲.mp3`（保持同名）；或直接改文末 `<audio>` 的 `src`
2. **换头像**：把新头像放进 `assets/`，替换 `寿星头像.png`（保持同名）
3. **换歌词**：在 `生日祝福-模板版.html` 的歌词区，改每行 `中文(zh)` / `英文(en)`，增删就复制/删掉整行 `<div class="l">`
4. 改完把模板版重命名为 `index.html` 再上传即可

> 说明：代码保留归属指纹水印（`一场跨越光年的宇宙旅行；晚安，辰星`），请勿删除。
